# Avatares por Género

Esta carpeta debe contener las siguientes imágenes PNG para los avatares basados en género:

- **masculino.png** - Avatar para usuarios con género "Masculino"
- **femenino.png** - Avatar para usuarios con género "Femenino"  
- **default.png** - Avatar por defecto para usuarios sin género o cuando falla la carga

Las imágenes deben ser cuadradas y se mostrarán en formato circular. Se recomienda un tamaño mínimo de 64x64 píxeles para buena calidad en diferentes tamaños de visualización.
